# Исходные материалы

В начальном коммите `0a7cf9ec2226122342a503177df975d55f2f1037` были только
`README.md` и один **многотомный** архив:

| Файл | SHA-256 |
| --- | --- |
| `3832310762.z01` | `1af4704f1e38a64c2d1a2ab152c3e4f7e8c60574a077ccf08a92b7f4619ef21a` |
| `3832310762.z02` | `84157579eab5bf31ae4c3402f5a1a9d8d6d1dd7aff622014cab2d12d3f548829` |
| `3832310762.zip` | `02f0938b001932c7f0cbd6df5c901ac70874e54c500bb8ce79f893b5fdcc2521` |

Это **три тома одного архива**, а не по одному архиву на каждый мод.
Внутри находились смешанные компоненты Югославии 1989, самостоятельной
Сербии (`old_world_*`, `serbia_tree1`) и радио (`piano_station`).
Исходные тома сохранены без изменений. Активные исходники — папки
`common`, `events`, `gfx`, `history`, `interface`, `localisation`, `map`, `music`
и корневой `descriptor.mod`, а не содержимое старых ZIP.

Для первоначального извлечения применялось объединение томов:

```sh
zip -s 0 3832310762.zip --out original-combined.zip
unzip original-combined.zip -d original
```

Не распаковывайте старый архив поверх исправленной сборки.

Два дополнительных состояния карты (`1082` — южная Воеводина и `1083` —
часть Боснии) тоже включены в федерацию 1989 года. Их исходный
`map/buildings.txt` сохранён: без него отсутствуют позиции зданий новых
состояний. Литорале (`736`, Триест) в 1989 году принадлежит Италии, а не
независимой Словении, поэтому не блокирует последующее освобождение Словении.

## Что намеренно не подключено из архива

- Полные старые `countrydiplomacyview.gui`, `countrypoliticsview.gui`,
  `frontendgamesetupview.gui` и декоративная HMB-обвязка: оставлен интерфейс
  установленной версии игры, а не глобальная замена устаревшими окнами.
- Полные копии `common/countries/colors.txt` и `cosmetic.txt`: оставлены
  только пользовательские косметические цвета в собственных файлах.
- Неиспользуемые копии `YUG_1936*` / `YUG_1939*`: у сценария 1989 года свой
  `Y89_YUG`, а у Сербии — `SER_1936`.
- Глобальная локализация и дубли vanilla-спрайтов музыкального плеера:
  добавлены только собственные названия, альбомная картинка и станция.
- Workshop-ID старого мода: локальный мод не должен наследовать чужую
  привязку публикации. У готовой сборки отдельный файл лаунчера `reworkl.mod`.

Сами композиции и остальная исходная графика взяты из предоставленного репозитория;
новая лицензия на чужие материалы этим изменением не выдаётся.


## Загрузочная графика 1.2.1

Три новые иллюстрации созданы с помощью ИИ для этой сборки и выбраны
пользователем: Белград, Динарские горы, штаб в 1989 году. Это не фотографии
реальных событий и не скриншоты запущенной игры. Фоны не используют
скопированные иллюстрации других модов. JPEG-превью находятся в
`website/assets/loading-*.jpg`, игровые текстуры — в `gfx/loadingscreens`.

Соглашение загрузки DDS из `gfx/loadingscreens` и `replace_path` сверено
с [публичным descriptor Kaiserreich](https://github.com/Kaiserreich/Kaiserreich-4/blob/master/descriptor.mod),
а стандартные ключи `LOADING_TIP_0` и далее — с его
[файлом локализации](https://github.com/Kaiserreich/Kaiserreich-4/blob/master/localisation/english/KR_common/Loading%20Tips%20l_english.yml).
Чужие изображения и тексты в сборку не копировались; добавлены собственные
подсказки. Это проверка соглашения файлов, не замена теста в движке.
