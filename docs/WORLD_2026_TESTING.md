# Проверка 2026: автоматизация и обязательный ручной тест

## Действительно выполненные проверки

Команды для текущей рабочей копии:

```sh
python scripts/validate_mod.py
python -m unittest discover -s tests -v
python scripts/build_mod.py
```

Валидатор контролирует 1255 регионов, 198 стран/территорий, 16549 видимых
провинций, 222 стратегических региона, согласованные файлы карты и SHA-256,
столицы и позиции армий, две даты, локализацию, атрибуцию и исходную музыку.
`tests/test_world_2026.py` отдельно проверяет полный список членов ООН,
наблюдателей и явно показанных спорных территорий, нормализацию несовместимых
пространств тегов CHI/TAI/IND/MAL/MAC, политику спорных границ и безопасное
развёртывание компактного источника растров.

`tests/scenario_harness.py` читает реальные скрипты старта: проверяет отсутствие
повторной инициализации/размножения армий, сброса фокусов/владения после загрузки,
сохранение Сербии 1936 и отсутствие старого календаря распада в новой кампании.
Это регрессионная модель, **не эмулятор движка HOI4**.

Синтаксический парсер PowerShell не доказывает работу установщика в Windows.
При отсутствии PowerShell его runtime-тесты должны явно пропускаться, а не
считаться успешно выполненными. CI содержит Windows 5.1/7; удалённый запуск CI
и запуск HOI4 не заявляются без полученных результатов.

## Alpha2: исправление маршрутизации запуска (2026-11-07)

Новая основная кнопка полного ZIP — `0_START_2026.bat`: проверяет, что рядом
полный 2.x, выполняет staged-установку, затем запускает установленный мод.
После меню/вылета и Enter сохраняет отчёт и ZIP из выбранных трёх логов.
Обычный Launch сравнивает версию/контрольные файлы со своим полным bundle
и не должен молча запускать старую установленную 1.x или другой build.

Сценарии ванили дополнительно перекрыты точными именами `blitzkrieg.txt` и
`the_gathering_storm.txt`; файлы намеренно пусты кроме комментариев. Только
`Y89_bookmarks.txt` задаёт две кампании. Checker отличает ноль сценариев
в заглушке от действительно подгруженной ванили и требует точное имя
`Reworkl - World 2026 v2.0.0-alpha2` в свежем system.log. Истории стран
изолированы `replace_path`, оставлены только 198 профилей и releasable YUG.

Выполнено:
- **162 теста: 128 успешных, 34 явно пропущенных** без настоящего PowerShell.
  В том числе 7 новых файловых/маршрутизационных контрактов, две новые
  мутационные проверки изоляции и канонического сценария; 27 HTTP-тестов.
- Шесть новых runtime-кейсов PowerShell добавлены для Windows CI, **но здесь
  пропущены**, а не объявлены успешно выполненными. Они проверяют отказ от
  запуска старой/изменённой сборки, one-click обновление старого payload,
  принятие пустых заглушек и ограниченный сбор без личного профиля.
- Три PowerShell-файла прошли tree-sitter без синтаксических ошибок.
- Полный `reworkl-2.0.0-alpha2.zip`: **70 854 712 байт**, 2908 записей;
  SHA-256 `e5a8a80b2cc169dd6c2e20a2cb2d99c86180e50dab9a2e0722845c980c35ba55`.
  CRC и проверка свежей распаковки прошли. Игровой payload и все 8 BAT-helper
  побайтно совпадают с исходниками; карта 1255/198/16549/222, 26 сохранённых
  медиафайлов не изменены. Исторические версионные архивы не перезаписаны.
- Сервер перезапущен с alpha2. Chromium скачал все 9 файлов настоящими
  кнопками с совпадающими размерами/именами/SHA-256; 6 размеров экрана,
  меню/клавиатура/FAQ/копирование без ошибок. Live API честно сообщает
  `engine_tested: false`.

Ни файловая overlay-модель, ни tree-sitter, ни эти 128 тестов не доказывают
реальную загрузку в HOI4. Новая сборка ещё требует Windows/игровой проверки.
Скриншот 1939 и прежний журнал с Combined/38 DLC не выдаются за доказательство
причины сбоя alpha1 или за результат alpha2.

## Зафиксированный результат 2026-11-07 — историческая alpha1

- Полный набор: **147 тестов, 119 успешных, 28 явно пропущенных** из-за
  отсутствующего PowerShell runtime. Нет упавших тестов. Отдельно 27/27 HTTP
  тестов сайта и 17/17 проверок новой географии/безопасного развёртывания.
- Tree-sitter: все три PowerShell-установщика разобраны без синтаксических
  ошибок, включая новые проверки ровно 1255 регионов. Это не runtime-тест.
- `reworkl-2.0.0-alpha1.zip`: 70 917 726 байт, 3002 записи;
  SHA-256 `6212df324a9bcbc304a0d3168987a90a8685a1bd3688d13b2ff85c23c316f526`.
  CRC всех записей прошёл. Повторная проверка свежей распаковки прошла;
  каждый игровой файл и BAT-helper совпадает с текущим исходником побайтно.
- Все 23 OGG и три выбранных загрузочных DDS совпадают с доставленной 1.2.4.
  Прежние версионные архивы 1.2.4/RU/RU2 не перезаписаны.
- Перезапущен сервер с полной 2.x; live API публикует правильные размер,
  версию и хеш. Chromium действительно скачал девять файлов через кнопки
  и проверил байты, имена вложений и SHA-256. Адаптивность и управление
  проверены на 1440/1280/1024/900/390/320 px без ошибок браузера.
- Проверены календарные границы: минимум 1936, максимум 2100.
- **Запуск настоящего HOI4 и Windows-установка не выполнены.** Показатель
  `engine_tested` в API намеренно равен `false`. Это альфа, не доказательство
  запуска, исправления шрифтов или точности современных вооружённых сил.

## Ещё необходимый тест на лицензированной HOI4 1.19.x

1. Распаковать новый полный ZIP в отдельную папку; закрыть игру, оставить Steam.
2. Выполнить `1_INSTALL.bat`, проверить резервную копию прежней папки Reworkl.
3. Выполнить `2_LAUNCH.bat`, затем `3_CHECK.bat`.
4. Убедиться, что загружен один Reworkl и `Active DLC Count: 0` в свежем журнале.
5. В новой игре увидеть две кампании: «Мир — 2026» и альтернативную Сербию 1936.
6. Выбрать 2026: проверить дату 01.01.2026, отдельные страны на всех континентах,
   восточный Тимор, Южный Судан, обе Кореи, Китай/Тайвань и независимые Балканы.
7. Проверить отсутствие наложенных/безвладельных регионов, вылета на чтении карты,
   неизвестных типов зданий/ресурсов, отсутствующих регионов снабжения/провинций.
8. Проверить русский текст страны и описания фокуса при English и Russian;
   файл шрифтов подключает штатные кириллические варианты, но рендеринг ещё
   требует проверки: исходная проблема `????` не объявляется решённой на ПК.
9. Запустить 2026, пройти несколько дней; сохранить/загрузить. Проверить, что
   армии не размножились, фокусы/границы не сбросились и события 1991 не появились.
10. Начать отдельно Сербию 1936: шесть дивизий находятся в Сербии, доступно
    авторское дерево из 131 фокуса; проверить региональные награды/Черногорию.
11. Проверить все три загрузочных DDS и проигрывание 23 исходных аудиотреков.

## Границы утверждений

Эта сборка — alpha политической карты. Текущие фронты, правители, реальные
армии, новые технологии и полные национальные деревья не верифицированы
и не заявляются. Подробная спорная география и оговорки — в WORLD_2026_RU.txt.
Старые системные логи пользователя относятся к предыдущему моду: их нельзя
выдавать за результаты теста 2026 или нового шрифтового исправления.
