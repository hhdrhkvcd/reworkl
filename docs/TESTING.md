# Проверки

## Автоматически

```sh
python scripts/validate_mod.py
python -m unittest discover -s tests -v
python scripts/build_mod.py
```

Валидатор не требует игры, сети и сторонних библиотек. Он проверяет:

- структуру Clausewitz-файлов, включая кавычки, комментарии и вложенные блоки;
- две закладки, стартовый диапазон дат, локализацию и отсутствие дублирующих ID;
- ссылки 190 фокусов четырёх деревьев и отсутствие циклов предпосылок;
- 31 пользовательского персонажа, их портреты и продвижение с правильной идеологией;
- 79 идей и ошибочное размещение игровых правил в числовых модификаторах;
- 213 включённых состояний карты, повторяющиеся провинции и границы федерации;
- стартовые позиции/шаблоны дивизий во всех восьми локальных OOB;
- локальные события, пространства имён и ссылки на деревья/OOB;
- соответствие всех 23 аудиофайлов, регистра имён, плейлиста, GUI и локализации;
- заголовки Ogg Vorbis, стерео и частоту 44,1 кГц;
- три DDS-загрузочных экрана: заголовок, размер 1920×1080, DXT1, длину данных,
  `replace_path`, отсутствие PNG-заглушек и локализацию десяти подсказок.

Тесты используют небольшой **моделирующий стенд** для календаря и флагов:
он исполняет только нужное подмножество команд. Это регрессионная проверка
логики мода, **не эмуляция HOI4**. Также проверяются повреждённые ссылки,
установка/обновление/откат установщика и содержимое готового ZIP.

При подготовке этой версии все 23 OGG были дополнительно полностью
декодированы через `libsndfile`/`soundfile`, с проверкой числа кадров и
конечных значений семплов. Единственная запись 48 кГц (`balada.ogg`)
пересэмплирована `soxr` VHQ в 44,1 кГц, повторно проверена после записи.
Эти библиотеки нужны только для этой дополнительной медиа-проверки,
не для установки, игры, стандартных тестов или сборки. Повторная полная
проверка (не изменяет аудиофайлы):

```sh
python -m pip install soundfile
python scripts/check_audio.py
```

Синтаксис проблемных команд сверялся с
[cwtools-hoi4-config](https://github.com/cwtools/cwtools-hoi4-config).
Репозиторий конфигурации не подменяет схему конкретной установленной игры.
Валидатор не гарантирует существование всех внешних vanilla/DLC технологий,
иконок, черт и модификаторов и не проверяет их движком.

## Установщик готового ZIP (1.2.2)

`tests/test_release_installer.py` содержит настоящие интеграционные вызовы
PowerShell: установка в Unicode-путь, создание абсолютного descriptor,
резервная копия, сохранность сохранений/JSON, регистрация на месте,
read-only проверка vanilla/своих закладок и отказ при неполном исходнике.
Если PowerShell отсутствует, эти **шесть тестов явно пропускаются**, а не
выдаются за прошедшие. В CI добавлен Windows job с настоящим PowerShell;
удалённый прогон пока не выполнялся.

При подготовке 1.2.2 PowerShell в локальном окружении отсутствовал,
получить runtime по разрешённой сети не удалось. Синтаксис скрипта дополнительно
проверен tree-sitter-powershell, но это **не исполнение на Windows**.
Реально выполнены тесты упаковки helper-файлов, их BOM/CRLF, отдельного
маленького ZIP и HTTP-скачивания. Запуск нового Windows-установщика здесь
не подтверждён; доступен ручной способ из [INSTALL.md](INSTALL.md).

## Обязательная ручная проверка в HOI4

### Чистый запуск

1. HOI4 1.19.x, отдельный набор с **одним** Reworkl; новая игра, русский язык.
2. Проверить обе даты и описания в меню. Проверить также английскую локализацию.
3. Начать Сербией в 1936: своя страна, 6 стартовых дивизий, авторское дерево
   из 131 фокуса. Босния, Хорватия, Косово, Черногория, Македония и Словения
   должны быть отдельными государствами.
4. Начать Югославией в 1989: все 19 федеральных областей принадлежат `YUG`
   до первого тика, 15 стартовых дивизий стоят на своей территории,
   есть президентство и три стартовых национальных духа.
5. Открыть деревья, портреты, политику, дипломатию, выбрать и закончить
   несколько фокусов. Проверить исправленный промышленный фокус Сербии.
6. Повторить запуск с используемыми вами DLC. Отдельно проверить без
   `No Step Back`, `By Blood Alone` и `Man the Guns`, если они отключены.

### Картинки загрузки

1. Полностью закрыть HOI4 и лаунчер. Заменить папку мода сборкой 1.2.1 или новее;
   не накладывать её поверх старой. Включить только Reworkl.
2. При запуске проверить одну из трёх сцен: Белград, горы, штаб.
   Все три не обязаны появляться в течение одного запуска.
3. Проверить обычный текст/индикатор загрузки: фон не должен быть чёрным,
   перевёрнутым, растянутым или перекрывать текст нечитаемой светлой зоной.
4. Повторить на используемом разрешении и на русском/английском языке.
   Первые десять стандартных ключей подсказок заменены текстами Reworkl;
   остальные подсказки установленной игры остаются её собственными.
5. Проверить `logs/error.log` на ошибки DDS и загрузочных файлов.

Превью в [LOADING_SCREENS.md](LOADING_SCREENS.md) показывают оформление,
а не выполнение этой проверки. Настоящий графический запуск здесь не делался.

### Календарь (исторический путь, без завершённой комиссии по гарантиям)

| Дата | Событие |
| --- | --- |
| 25 июня 1991 | Словения и Хорватия |
| 8 сентября 1991 | Македония |
| 25 сентября 1991 | Эмбарго на оружие |
| 6 апреля 1992 | Босния и Герцеговина |
| 30 мая 1992 | Комплексные санкции |
| 3 июня 2006 | Черногория |
| 17 февраля 2008 | Декларация Косово |

- Сохраняться непосредственно до и после событий, затем загружать сохранение.
  Не должно быть повторных событий, повторной выдачи армий, сброса фокусов
  или возвращения отделившихся территорий в федерацию.
- На мирной ветке завершить «Комиссию по гарантиям» до 25 июня 1991:
  календарь распада и санкций не должен выполняться.
- В сценарии 1936 года календарь 1989 года не должен включаться даже при
  перемотке календаря или вызове соответствующего события через консоль.
- После завершения Дейтонского фокуса проверить снятие духа санкций и торговых эмбарго.

### Музыка

1. Выбрать станцию «Турбо-фолк — Reworkl», отключить остальные станции.
2. Вручную пройти все **23** композиции; проверить названия, паузу,
   переключение и случайный порядок, отсутствие тишины на проблемных файлах.
3. Повторить за Сербию и Югославию, после сохранения/загрузки.

### Журнал

Запуск с `-debug`; изучить `logs/error.log`. Для сообщения о проблеме нужны
сам журнал, версия игры, DLC, сценарий, дата, действия для воспроизведения.
Ни запуск движка, ни графический/игровой smoke-test здесь не выполнялись:
HOI4 в окружении разработки отсутствует.


## BAT / no-DLC workflow 1.2.3

`python -m unittest discover -s tests -p test_bat_workflow.py -v` checks the
small deterministic toolkit, ASCII/CRLF BAT wrappers, source filtering,
legacy 1.2.0 version preservation, isolated data, DLC descriptor discovery,
backups/rollback, quoted direct launch arguments, stale-log rejection and
reversible optional game-data redirection. Runtime tests execute REAL
PowerShell against TEMP fixtures; Start-Process is mocked so no game runs.
On hosts without PowerShell, those cases explicitly skip. Windows CI runs
them with both Windows PowerShell 5.1 and PowerShell 7. Remote CI is not
implied by a local test result.

The actual no-DLC game smoke test remains separate: install, keep Steam up,
run 2_LAUNCH.bat, wait for the main menu, then run 3_CHECK.bat. It must see
fresh setup/system logs, only Reworkl active, Y89_bookmarks.txt with both
bookmarks, no vanilla bookmarks and Active DLC Count: 0. Then separately
play both campaigns and exercise the Serbia non-NSB tank-tech fallback,
focus rewards, loading screens, radio and save/reload. Passing parser or
fixture tests does not establish runtime/DLC compatibility of the game.


### File.Replace regression (BAT 1.2.4)

The user reported Windows PowerShell throwing an invalid-path exception only
on Launch, after the first Install had created the settings files. The writer
passed `$null` as File.Replace's third string argument. The regression guard
rejects that call and requires a real sibling backup path. The real-runtime
case overwrites the same file three times in a path with spaces, apostrophes
and non-ASCII characters, and checks both bytes and cleanup. The Windows CI
matrix includes powershell.exe (5.1), not only pwsh.exe. Local runtime skips
remain explicit when the host has no PowerShell; a syntax/static pass is not
a Windows runtime reproduction or an HOI4 smoke test.
