# Reworkl — русский перевод RU2

Это исправление текстов МОДА, в том числе когда язык самой HOI4 — English.
Главное меню, обычные кнопки и другие тексты БАЗОВОЙ ИГРЫ этот пакет не переводит. Если меню остаётся английским, это само по себе не означает, что перевод мода не установился.

## Зачем новый пакет

Прежний патч содержал только l_russian. При выбранном English игра использует l_english. В RU2 добавлен отдельный слой с теми же русскими текстами для режима English, без изменения игровых механик и без правок настроек.

## Одной кнопкой

1. Полностью закрой HOI4 и Paradox Launcher.
2. Распакуй ВЕСЬ новый ZIP в отдельную новую папку. Не запускай BAT прямо из архива.
3. Дважды щёлкни APPLY_RUSSIAN.bat. Он найдёт установленный мод в %PUBLIC%\HOI4MODS\reworkl, проверит его и пакет, сохранит прежние файлы локализации и обновит только перевод.
4. В окне должно появиться:

   [RESULT] LOCALISATION_FILES_VERIFIED

5. Запускай игру своим прежним рабочим 2_LAUNCH.bat. Не повторяй 1_INSTALL и не используй План Б ради перевода.
6. Проверь именно элементы мода: например, в дереве Сербии 1936 фокус премий рабочим должен называться «Премии рабочим». Тексты мода должны быть русскими при языках игры Russian и English.

Если мод установлен в другое место, пакет не создаёт пустую подставную папку. Можно явно указать существующую рабочую папку:

   APPLY_RUSSIAN.bat -ModDir "D:\Games\Mods\reworkl"

Для другой базы BAT-установки есть параметр -BaseDir.

## Если по-прежнему не видно перевода

Рядом с APPLY_RUSSIAN.bat появится REWORKL_RUSSIAN_REPORT.txt. Пришли этот текстовый файл и скрин именно английских фокусов/событий в игре. Отчёт показывает проверенную папку и состояние восьми YML; проверка файлов не доказывает, что движок читает именно эту копию мода.

Для проверки файлов без установки:

   APPLY_RUSSIAN.bat -CheckOnly

Отчёт сохраняется только локально, автоматически никуда не отправляется.

## Что не меняется

Не меняются hoi4.exe, настройки языка, dlc_load.json, userdir.txt, descriptor.mod, старый Reworkl-Bat.ps1 и 2_LAUNCH.bat, игровые эффекты, музыка, графика и сохранения. Запущенные процессы не завершаются. Переустановка и новая кампания специально ради перевода не нужны.

Восемь YML — семь обычных русских файлов и один намеренный русский слой для English в localisation/replace. Идентификаторы и подстановки сохранены. Исходные английские файлы не удаляются и не переписываются.

До записи сохраняются точные копии существовавших файлов вне папки мода, в reworkl-russian-backups рядом с ней. Путь указан строкой [BACKUP]. При обычной ошибке копирования установщик пытается восстановить прежние файлы; при ошибке восстановления копии остаются для ручного восстановления. Резервная копия относится к состоянию перед запуском BAT, а не до ручной распаковки поверх мода.

Чтобы базовое меню тоже стало русским, отдельно выбери русский язык самой игры. Этот пакет намеренно не правит пользовательские языковые настройки.

Ограничения проверки: здесь проверяются структура/кодировка, полнота ключей, контрольные суммы и упаковка. Запуск HOI4 и Windows PowerShell в этой среде недоступен; это не утверждение об успешном тесте установщика на твоём ПК.

Для разработчика: python scripts/build_russian_fix.py
