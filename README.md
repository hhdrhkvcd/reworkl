# Reworkl — Мир 2026, Сербия и Turbo-folk

**2.0.0-alpha2: основной старт — 1 января 2026 года вместо 1989.**
Это предварительная сборка: офлайн-проверки не заменяют запуск в HOI4.

| Кампания | Содержание |
| --- | --- |
| **Мир — 2026** | Собственная согласованная карта провинций; 1255 регионов, 198 стран/отдельно показанных территорий по всему миру; современные национальные флаги. По умолчанию выбрана Сербия, но доступны остальные страны. |
| **Сербия — 1936 (альтернативная)** | Сохранены 131 авторский фокус, исторические персонажи и шесть стартовых дивизий. Ссылки на регионы и позиции войск перенесены на новую карту. |
| **Радио / загрузочная графика** | Сохранены все 23 исходные композиции и три ранее выбранные загрузочные иллюстрации. |

## Исправление запуска alpha2

- Новая единая кнопка **`0_START_2026.bat`** сначала обновляет весь мод, потом
  запускает его, а не подхватывает старую установленную Combined/1.x.
- Обычный `2_LAUNCH` из полного ZIP отказывается молча запускать другую версию
  или несовпадающий файл сценариев. Внешнее имя мода содержит номер сборки.
- Канонические имена файлов ванильных сценариев перекрыты пустыми заглушками;
  только `Y89_bookmarks.txt` добавляет две действительные кампании.
- Истории стран из ванили изолированы от новой карты; старые неиспользуемые
  профили удалены из payload. Остаются 198 активных профилей и releasable YUG.
- Сбор диагностик ограничен тремя логами по 1 МиБ и текстовым отчётом;
  сохранения, Steam, настройки аккаунта и crash dump не включаются.

Это исправление файлов и маршрутизации запуска, не подтверждённый smoke test HOI4.

## Важные ограничения

- Это **политическая карта, не карта военных линий фронта**. Крым/Севастополь
  показаны в международно признанных границах Украины, Голанские высоты — Сирии;
  Косово, Тайвань и Западная Сахара показаны отдельно с оговорками о статусе.
  Полная политика спорных территорий: [WORLD_2026_RU.txt](WORLD_2026_RU.txt).
- Вооружение, маленькие стартовые бригады, правительства и восемь общих фокусов
  условные. Реальные президенты, результаты выборов, современная техника,
  численность армий и национальные деревья для всех стран не заявляются.
- Население/промышленность — исходные игровые величины, не статистика 2026 года.
- **Обе даты используют одну географическую сетку.** Сербия 1936 — альтернативная
  кампания; мировой фон не является реконструкцией исторического 1936 года.
- Нужна **новая игра**. Старые сохранения 1989 не совместимы с новой географией,
  но установщик их не удаляет.
- Нет локального Windows/HOI4: запуск движком и исправление `????` требуют
  проверки на игровом компьютере. Добавлены кириллические варианты штатных
  шрифтов для English/Russian; это не доказательство успешного рендеринга.

## Windows: полный ZIP и BAT, без DLC

1. Распаковать **весь** `reworkl-2.0.0-alpha2.zip` в новую папку, не поверх
   старой распаковки. Маленький BAT-комплект и RU2 не содержат новую карту.
2. Закрыть игру и Paradox Launcher, оставить Steam запущенным.
3. Выполнить **`0_START_2026.bat`**: он сначала установит полную новую карту,
   затем запустит именно установленную версию. Выбрать **«Мир — 2026»**.
4. После меню или вылета вернуться в окно BAT и нажать Enter: рядом сохранятся
   `REWORKL_START_RESULT.txt` и ZIP с правильными логами. Не нужно искать их
   в старых Документах. Отдельные `1_INSTALL` / `2_LAUNCH` / `3_CHECK` сохранены.

Мод по умолчанию: `%PUBLIC%\HOI4MODS\reworkl`. Предыдущая папка мода и
настройки сохраняются в резервной копии, затем папка заменяется целиком,
без смешивания старых и новых регионов. Сохранения, чужие моды и база
лаунчера не удаляются. Найденные DLC отключаются только в выделенном JSON;
базовая лицензия Steam необходима, файлы игры/DLC не разблокируются.
Python и установка Millennium Dawn пользователю не нужны.

[Подробная установка](docs/INSTALL.md) · [Границы и ограничения](WORLD_2026_RU.txt).

## Сборка из исходников

Python 3.10+, стандартная библиотека. Готовый ZIP включает развёрнутую карту.

```sh
python scripts/materialize_world_map.py
python scripts/generate_world_2026.py
python scripts/validate_mod.py
python -m unittest discover -s tests -v
python scripts/build_mod.py
python website/server.py --host 0.0.0.0 --port 3000
```

`assets/world_2026/map-data.tar.xz` — обязательный компактный источник восьми
согласованных файлов карты (около 6,4 МБ). Развёрнутые BMP/unitstacks исключены
из Git, восстанавливаются при проверке/сборке. Архив проверяется SHA-256,
не допускает произвольных путей и не перезаписывает изменённые файлы молча.
Не помещайте в Git полный сторонний мод или копию игровых файлов.

- `data/world_2026/world.json` — проверяемая география, нормализация тегов,
  политика владения, столицы и миграция старых ID.
- `scripts/import_world_reference.py` — разработческий импорт из заранее
  извлечённой **закреплённой** географической версии; не часть установки.
- `scripts/generate_world_2026.py` перегенерирует `history/states` и игровые
  файлы из данных. Ручные изменения в генерируемых файлах будут заменены.
- Для повторного импорта/конвертации флагов/рендера предпросмотра нужны
  дополнительные зависимости из `requirements-world-assets.txt`.
- Скрипты языковых патчей 1.x сохранены для совместимости, но для 2026 нужен
  полный ZIP; русский текст и шрифтовая конфигурация уже включены.

## Что проверяется

Структура Clausewitz, весь набор государств, отсутствие пропавшей суши и
дублирующихся провинций, стратегические регионы/снабжение, владельцы столиц
и стартовых армий, согласованные BMP и их контрольные суммы, 594 флага,
две даты, защита от повторной инициализации после загрузки сохранения,
сохранение сербского дерева, BOM/локализация, 23 аудиозаписи, три DDS,
упаковка, безопасное развёртывание и HTTP-загрузки.

Модель старта в тестах **не является эмулятором HOI4**. Тесты PowerShell
пропускаются без настоящего рантайма; синтаксический парсер не заменяет их.
См. [план проверки в игре](docs/WORLD_2026_TESTING.md).
