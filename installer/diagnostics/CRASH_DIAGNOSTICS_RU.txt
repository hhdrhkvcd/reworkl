REWORKL — СБОР СВЕЖЕГО ВЫЛЕТА БЕЗ ПЕРЕУСТАНОВКИ
Версия сборщика 1. Мод, карта и установка не меняются.

По отчёту Alpha3 установка 1255 регионов завершилась успешно.
Если игра показала загрузку и закрылась, а в отдельном профиле нет логов,
нужен текущий exception/meta или свежие журналы из фактической папки игры.
Сами строки NO_LOG не устанавливают причину вылета.

КАК ПОЛЬЗОВАТЬСЯ
1. Распакуй ЭТОТ маленький ZIP в любую доступную для записи папку.
   Не запускай BAT из окна архива. Ничего в папку мода копировать не надо.
2. Запусти COLLECT_REWORKL_CRASH.bat. Игру повторно запускать не требуется:
   время последней попытки сохранено установленным BAT-инструментом.
3. Рядом появится REWORKL_CRASH_DIAGNOSTICS_...zip. Пришли именно его.
   Текстовый REWORKL_CRASH_REPORT_...txt можно сначала просмотреть.

Проверяются отдельный профиль Reworkl, системные Документы/OneDrive,
папки из userdir.txt и gameDataPath, если они заданы. Источники и UTC-время
указаны в SOURCES.txt и REPORT.txt. Журналы от другого профиля не выдаются
за подтверждение запуска Мира 2026 или отсутствия активных DLC.

Сборщик не запускает и не завершает процессы, не устанавливает мод,
не меняет userdir.txt, launcher-settings.json, dlc_load.json или настройки.
Не удаляет файлы, не включает/открывает DLC и не читает базу аккаунтов.
Сохранения, дампы памяти и вся папка crashes в архив НЕ попадают.

Дополнительно проверяются до пяти событий Application Error (ID 1000)
только для hoi4.exe после времени BAT-запуска. Из них берутся лишь имя
модуля, код исключения, версия, путь и время; не весь журнал Windows.
Права администратора не запрашиваются, ошибка доступа не мешает остальному.

Копируются только хвосты system/setup/error по 1 МиБ и небольшие
meta.yml/exception.txt из свежих crash-кандидатов. Общий лимит содержимого
8 МиБ. Старые crash-даты внутри текста проверяются отдельно, даже если
старую папку недавно скопировали. Каталоги-ссылки/oversized text пропускаются.
При отсутствии корректного времени BAT-запуска старые логи не копируются.
Проверка времени — способ отбора кандидатов, не доказанная причина сбоя.

Архив может содержать пути с именем пользователя, время, список модов
и технические сведения об оборудовании из отчёта игры. Можно проверить
его перед отправкой. Он создаётся только рядом с этим сборщиком.
Нужен штатный Windows PowerShell 5.1+; Python и права администратора не нужны.
Если вместо ZIP появилась ошибка, пришли фотографию окна сборщика.
