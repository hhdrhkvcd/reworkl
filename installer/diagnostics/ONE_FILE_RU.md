# Один файл для сбора вылета

Если в старой папке мода нет `COLLECT_REWORKL_CRASH.bat`, это нормально:
сборщик выпускается отдельно и не входил в установленную Alpha3.
`START_RESULT.txt` и `SOURCES.txt` из старой проверки не являются новым
отчётом сборщика.

Для пользователя доступен **самостоятельный** `COLLECT_REWORKL_CRASH.bat`:

1. Скачать BAT в доступную для записи папку, например «Загрузки».
2. Запустить двойным щелчком. Соседний PS1, распаковка мода, Python,
   повторный запуск игры и права администратора не нужны.
3. Рядом появятся **новые** `REWORKL_CRASH_DIAGNOSTICS_….zip` и
   `REWORKL_CRASH_REPORT_….txt`. Отправить созданный ZIP, не исходный BAT
   и не прежний `START_RESULT.txt`. Если появилась ошибка — прислать фото окна.

Самостоятельный BAT и BAT из трёхфайлового архива имеют одинаковое имя,
но первый содержит сборщик внутри, а второму нужен соседний PS1.
Не нужно заменять файлы мода или копировать сборщик в его папку.

## Сборка и проверка

```sh
python scripts/build_crash_diagnostics.py --standalone
python -m unittest discover -s tests -p test_crash_diagnostics.py -v
```

Результат: `releases/COLLECT_REWORKL_CRASH.bat`.
Обычный вызов сборщика без `--standalone` по-прежнему собирает исходный
трёхфайловый ZIP; ранее выданные архивы не перезаписываются новой формой BAT.

BAT содержит читаемый, неизменённый по логике PowerShell-сборщик, не скрытый
или загружаемый из сети код. Windows PowerShell читает его из самого файла.
Путь к BAT передаётся как значение переменной окружения, а не вставляется
в исполняемую строку; вывод записывается рядом с BAT, а не во временную папку.
Командная строка короткая и не содержит самого содержимого сборщика.

Тесты Windows запускают настоящий CMD и штатный Windows PowerShell, включая
пути с кириллицей, пробелами, апострофом, `!`, `&` и скобками. Проверяется
создание нового ZIP без соседних файлов, неизменность входных данных,
очистка собственного временного каталога и возврат ошибки вместо ложного успеха.
Игра в этих тестах не запускается.

Ограничения, приватность и отбор по времени те же, что в
[CRASH_DIAGNOSTICS_RU.txt](CRASH_DIAGNOSTICS_RU.txt).
Это сбор технических данных, **не исправление вылета**.
