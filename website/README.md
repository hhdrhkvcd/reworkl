# Сайт скачивания Reworkl — Мир 2026

Русскоязычная страница полной **2.0.0-alpha3**: дата 01.01.2026,
198 стран/территорий, 1255 регионов и дополнительная Сербия 1936.
Основная кнопка запуска из полного ZIP — `0_START_2026.bat`: установка,
запуск и сбор выбранных логов после нажатия Enter. Маленький BAT-комплект
без карты не заменяет полный архив. Это альфа политической карты; сайт не выдаёт её за проверенный запуск HOI4.
Все шрифты, иллюстрации и скрипты локальные, без CDN и аналитики.

## Запуск

Из корня репозитория, Python 3.10+:

```sh
python scripts/build_mod.py
python website/server.py --host 0.0.0.0 --port 3000
```

Node.js и дополнительные Python-пакеты для сервера/сборки не нужны.
Сборщик разворачивает согласованные растры из компактного источника
`assets/world_2026/map-data.tar.xz`. Полный ZIP уже содержит готовую карту;
пользователю игры не нужны Python, архивы исходников или Millennium Dawn.

Если полного ZIP для версии из `descriptor.mod` нет, сервер собирает его.
Существующий ZIP автоматически **не пересобирается** после правки исходников:
сначала явно выполните сборщик, затем перезапустите сервер. Версия, размер
и SHA-256 кэшируются при старте; HTML и API должны ссылаться на один архив.
Существующие исторические RU/RU2 ZIP также не перезаписываются при запуске.

Порт можно передать через `--port` или `PORT`. Сервер слушает `0.0.0.0`,
принимает host предпросмотра Arena и использует относительные ссылки.
Предпросмотр не является постоянным хостингом. Для публикации нужны свой
HTTPS/reverse proxy и место для полной сборки.

## Основные маршруты

- `/` — страница скачивания, возможностей и ограничений альфы.
- `/download/reworkl-2.0.0-alpha3.zip` — полный готовый ZIP с картой и BAT.
- `/download` — короткий адрес текущего полного архива.
- `/api/release` — версия, размер, SHA-256, `start_date`, `world_entities`,
  `world_states`, `release_stage`, `engine_tested` и дополнительные файлы.
- `/world-2026.txt` — политика спорных территорий и ограничения географии.
- `/installation.txt` — установка отдельным текстовым файлом.
- `/healthz` — доступность сервера и архива.
- `/download/reworkl-bat-nodlc.zip` — маленький BAT-комплект **без карты**.
  Для перехода с 1989 нужен полный ZIP, а не только этот комплект.
- `/repair` — альтернативный маленький комплект подключения существующей
  установки; не заменяет полную сборку 2026.

Старые `/download/reworkl-russian-fix-2.zip` и
`/download/reworkl-russian-localisation.zip` сохранены в архивном разделе 1.x.
Они не обновляют год или границы. Кириллические шрифтовые настройки и русский
слой для English уже входят в 2.x; устранение `????` в настоящей игре ещё
нужно проверить. Базовое меню HOI4 зависит от языка самой игры.

Ручные `/download/reworkl.mod` (историческая 1.2.0),
`/download/reworkl-current.mod`, `/download/reworkl-windows-ascii-files.zip`
и `/windows-path.txt` остаются альтернативой BAT. Оба одиночных дескриптора
скачиваются как `reworkl.mod`, с явно подписанными версиями и одним путём
`C:/HOI4Mods/reworkl`. Не смешивайте этот способ с BAT-профилем.

Загрузка поддерживает attachment, HEAD, одиночные Range, If-Range и ETag.
Метаданные дополнительных файлов содержат собственные размер и SHA-256.
Маленькие комплекты используют `Cache-Control: no-cache`. Полные архивы
читаются порциями. Никакого поддельного прогресса или обещания завершения.
Публичный корень не совпадает с репозиторием: `.git`, журналы, исходники
и произвольные пути через HTTP недоступны.

## Проверки

```sh
python -m unittest discover -s tests -p 'test_web*.py' -v
python -m unittest discover -s tests -v
```

2026-11-07, alpha2: 27 HTTP-тестов сайта прошли; полный набор — 162 теста,
128 успешных и 34 явно пропущенных из-за отсутствующего PowerShell runtime.
Chromium проверил реальные кнопки девяти загрузок, имена/размеры/SHA-256,
размеры экрана 1440/1280/1024/900/390/320 px, клавиатурные вкладки,
копирование, FAQ, меню и отсутствие браузерных ошибок. Это проверка сайта,
а не запуска HOI4. Подробный ручной план: `docs/WORLD_2026_TESTING.md`.
