REWORKL — ФАЙЛЫ ДЛЯ ПРОВЕРКИ ПУТИ C:\HOI4Mods\reworkl

Это описания мода для лаунчера, НЕ полный мод и НЕ установщик.
Проблема с кириллицей пока не доказана. Этот способ позволяет проверить
подключение данных через отдельный путь на латинице без переименования
профиля Windows и без изменений DLC/сохранений.

В комплекте:
- 1.2.0/reworkl.mod — для ранее скачанной сборки 1.2.0;
- {{CURRENT_VERSION}}/reworkl.mod — для полной сборки {{CURRENT_VERSION}} с сайта.

ВЫБЕРИ ТОЛЬКО ОДИН ФАЙЛ ПО ВЕРСИИ УСТАНОВЛЕННОГО МОДА.
Версия самого мода указана в его descriptor.mod, это не версия игры HOI4.
Вариант для полной сборки сохраняет также replace_path для загрузочных картинок.

1. Полностью закрой игру и Paradox Launcher.
2. Создай C:\HOI4Mods и скопируй В НЕГО целиком папку reworkl.
   Старую копию не удаляй. Не переименовывай папку пользователя Windows.
3. Проверь, что существует именно:
   C:\HOI4Mods\reworkl\common\bookmarks\Y89_bookmarks.txt
   Не должно быть лишнего уровня reworkl\reworkl.
4. Открой пользовательскую папку игры, где находятся logs и dlc_load.json:
   обычно Документы\Paradox Interactive\Hearts of Iron IV.
   Сохрани резервную копию внешнего mod\reworkl.mod.
5. Положи выбранный скачанный reworkl.mod в подпапку mod этой папки данных.
   Это НЕ внутренний C:\HOI4Mods\reworkl\descriptor.mod — его пока не меняй.
   В архиве бери сам файл из папки своей версии, а не всю папку версии.
6. Имя установленного внешнего файла должно быть ровно reworkl.mod.
   Если браузер добавил (1) к имени, при переносе убери этот суффикс.
   Это НЕ reworkl.mod.txt и НЕ reworkl (1).mod.
   Скачанные файлы уже в ASCII/UTF-8, без Markdown-кавычек и лишних блоков.
7. В dlc_load.json после запуска должен быть выбран mod/reworkl.mod.
   Если он уже выбран, менять JSON не нужно. Старый Yugoslavia_1989_FIXED.mod
   не используется этой записью. Не соединяй несколько описаний в один файл.
8. Запусти игру из лаунчера с тем же набором и проверь новую игру:
   ожидаются Югославия 1989 и Сербия 1936.

Обычный INSTALL_REWORKL.cmd — ДРУГОЙ способ установки, в Документы.
Не запускай его поверх этого ручного варианта: он создаст другой путь.

Если снова только 1936/1939, нужна проверка файлов ПОСЛЕ запуска:
- внешнего mod\reworkl.mod;
- common\bookmarks\Y89_bookmarks.txt из фактической папки мода;
- свежих dlc_load.json и setup.log.
Для отправки в чат можно сделать отдельную копию .mod с расширением .txt,
но сам рабочий файл не переименовывать.

Ни запуск HOI4, ни исправление причины сбоя этим файлом не подтверждаются.
